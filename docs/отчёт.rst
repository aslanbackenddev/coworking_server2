Цель этапа
----------

Изучить стандарт WSGI и создать минимальное серверное
приложение, которое возвращает стартовую HTML-страницу,
прочитанную из файла.

Что сделано
-----------

1. Изучен стандарт WSGI.
2. Создана структура проекта.
3. Написано WSGI-приложение в ``app.py``.
4. Написан скрипт запуска ``run.py``.
5. Создана стартовая HTML-страница ``templates/index.html``.
6. Реализована обработка 404.

Результат
---------

Работающий веб-сервер на порту 8000.

Выводы
------

Стандарт WSGI позволяет писать веб-приложения без
сторонних фреймворков.
