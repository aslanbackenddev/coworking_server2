1. Общее описание
----------------------------------------------------------


Разрабатывается веб-приложение «Коворкинг», предназначенное
для просмотра и бронирования рабочих мест. Система
позволяет пользователям находить свободные места,
бронировать их на определённое время, а также управлять
своими бронированиями.

----------------------------------------------------------
2. Перечень функций системы
----------------------------------------------------------

2.1. Функции гостя (неавторизованный пользователь)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

===  ===========================  ==========================================
 №    Функция                      Что происходит
===  ===========================  ==========================================
 1    Открыть главную страницу     Сервер отдаёт HTML главной страницы
 2    Зарегистрироваться           Ввод имени, email, пароля → проверка
                                   → запись в БД → вход
 3    Войти                        Ввод email и пароля → проверка
                                   → создание сессии
 4    Посмотреть список мест       Выборка всех мест из БД → отрисовка
                                   страницы
===  ===========================  ==========================================

2.2. Функции пользователя (авторизован)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

===  ===========================  ==========================================
 №    Функция                      Что происходит
===  ===========================  ==========================================
 5    Посмотреть список мест       То же, но с кнопкой «Забронировать»
 6    Забронировать место          Форма (место + дата + время) → проверка
                                   занятости → запись в БД
 7    Посмотреть свои брони        Выборка броней текущего пользователя
                                   → список
 8    Отменить бронь               Нажатие «Отменить» → удаление/пометка
                                   брони → обновление списка
 9    Выйти                        Удаление сессии → редирект на главную
===  ===========================  ==========================================

2.3. Функции администратора
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

===  ===========================  ==========================================
 №    Функция                      Что происходит
===  ===========================  ==========================================
 10   Добавить место               Форма (название, описание, цена)
                                   → запись в БД
 11   Удалить место                Нажатие «Удалить» → удаление из БД
                                   (если нет активных броней)
 12   Посмотреть все брони         Выборка всех броней всех пользователей
===  ===========================  ==========================================

3. Дизайн сайта
----------------------------------------------------------

3.1. Страницы приложения
~~~~~~~~~~~~~~~~~~~~~~~~

- **Главная страница** — приветствие и навигация.
- **Страница входа** — форма авторизации.
- **Страница регистрации** — форма создания аккаунта.
- **Страница списка мест** — каталог рабочих мест.
- **Страница новой брони** — форма выбора времени.
- **Страница «Мои брони»** — список личных броней.


3.3. Сценарии (что нажимаем → что происходит)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Сценарий 1. Регистрация**

1. Гость нажимает кнопку «Регистрация» в шапке сайта.
2. Открывается страница с формой (имя, email, пароль).
3. Гость заполняет поля и нажимает кнопку «Создать аккаунт».
4. Если данные введены верно, система переносит его на
   страницу «Список мест» (пользователь уже авторизован).

**Сценарий 2. Вход**

1. Гость нажимает кнопку «Вход» в шапке сайта.
2. Открывается страница с формой (email, пароль).
3. Вводит данные и нажимает кнопку «Войти».
4. Система переносит его на страницу «Список мест».

**Сценарий 3. Бронирование места**

1. Пользователь на странице «Список мест» нажимает
   кнопку «Забронировать» напротив нужного места.
2. Открывается страница «Новая бронь» с формой выбора
   даты и времени.
3. Выбирает время, жмёт кнопку «Забронировать».
4. Если место свободно, система переносит пользователя
   на страницу «Мои брони», где появляется новая запись.
5. Если место занято — появляется сообщение «Это время занято».

**Сценарий 4. Отмена брони**

1. Пользователь на странице «Мои брони» нажимает
   кнопку «Отменить» напротив нужной брони.
2. Система запрашивает подтверждение действия.
3. После подтверждения бронь исчезает из списка.

**Сценарий 5. Добавление места (админ)**

1. Администратор открывает страницу «Управление местами».
2. Заполняет поля (название, описание, цена) и нажимает
   кнопку «Добавить».
3. Новое место появляется в общем списке на странице
   «Список мест».
