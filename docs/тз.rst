----------------------------------------------------------
1. Введение
----------------------------------------------------------

В рамках курсовой работы разрабатывается серверная часть
веб-приложения для бронирования рабочих мест в коворкинге.

Ключевое условие: **готовые веб-фреймворки и библиотеки не
используются**. Всё пишется самостоятельно на языке Python с
опорой только на стандартную библиотеку. По сути создаётся
свой мини-фреймворк, работающий по стандарту WSGI.

----------------------------------------------------------
2. Цель работы
----------------------------------------------------------

Разработать серверное приложение на языке Python, реализующее
интерфейс **WSGI** (Web Server Gateway Interface), без
использования готовых веб-фреймворков.

----------------------------------------------------------
3. Задачи
----------------------------------------------------------

1. Изучить стандарт WSGI и принцип его работы.
2. Реализовать минимальный WSGI-сервер.
3. Настроить чтение HTML-файлов и отдачу их клиенту по
   сетевому адресу.
4. Реализовать обработку ошибки 404 для неизвестных адресов.

----------------------------------------------------------
4. Требования
----------------------------------------------------------

4.1. Функциональные требования
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Сервер слушает сетевой порт (по умолчанию 8000).
2. На запрос ``GET /`` возвращает стартовую страницу.
3. Стартовая страница хранится в отдельном HTML-файле.
4. Сервер читает HTML-файл с диска и возвращает его
   содержимое в ответ.
5. На запрос по неизвестному адресу возвращается ответ
   ``404 Not Found``.

4.2. Нефункциональные требования
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- Язык реализации: Python 3.10+.
- Разрешена только стандартная библиотека Python.
- Запрещены сторонние фреймворки: Flask, Django, FastAPI.

----------------------------------------------------------

- **Работа с файлами:** модуль ``os``

7. Планируемый результат
----------------------------------------------------------

Работающий веб-сервер, доступный по адресу
``http://localhost:8000``, который:

- на запрос ``/`` возвращает стартовую HTML-страницу;
- на остальные адреса возвращает 404;
- запускается командой ``python run.py``;
- останавливается по ``Ctrl + C``.
