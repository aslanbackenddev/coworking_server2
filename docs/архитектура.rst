==========================================================
Архитектура WSGI-сервера
==========================================================

Общая схема
-----------

.. code-block:: text

   Клиент (браузер)
        │
        │ HTTP-запрос
        ▼
   ┌─────────────────────────────┐
   │   WSGI-сервер (wsgiref)     │
   └──────────────┬──────────────┘
                  │
                  ▼
   ┌─────────────────────────────┐
   │   Приложение (app.py)       │
   └──────────────┬──────────────┘
                  │
                  ▼
   ┌─────────────────────────────┐
   │   templates/index.html      │
   └──────────────┬──────────────┘
                  │
                  │ HTTP-ответ
                  ▼
   Клиент (браузер)

Слои приложения
---------------

1. **Транспортный слой** — ``wsgiref.simple_server``.
2. **Прикладной слой** — функция ``application()``.
3. **Слой данных** — папка ``templates`` с HTML-файлами.

Ключевые понятия WSGI
---------------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Понятие
     - Описание
   * - ``environ``
     - Словарь с данными запроса.
   * - ``start_response``
     - Функция для передачи статуса и заголовков.
   * - Возврат
     - Список байтов — тело ответа.

Используемые паттерны
---------------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Паттерн
     - Где применяется
   * - Front Controller
     - Единая точка входа ``application()``.
   * - Template Method
     - Чтение шаблонов через ``read_template()``.
