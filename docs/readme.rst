==========================================================
Коворкинг — серверное приложение на WSGI
==========================================================

Описание
--------

Минимальный веб-сервер на Python, реализованный по стандарту
WSGI. Возвращает стартовую HTML-страницу по адресу
``http://localhost:8000``.

Проект создаётся в рамках курсовой работы по дисциплине
«Проектирование и архитектура программных систем».

Требования
----------

- Python 3.10 или выше
- Стандартная библиотека Python (без сторонних фреймворков)

Установка
---------

1. Скопировать проект.

2. Установить docutils (только для сборки документации):

   .. code-block:: bash

      pip install docutils

Запуск
------

Из корневой папки проекта:

.. code-block:: bash

   python run.py

Ожидаемый вывод:

.. code-block:: text

   Сервер запущен: http://localhost:8000
   Нажмите Ctrl+C для остановки

Открыть в браузере:

.. code-block:: text

   http://localhost:8000

Остановка
---------

Нажать ``Ctrl + C`` в терминале, где запущен сервер.

Структура проекта
-----------------

.. code-block:: text

   coworking_server/
   ├── app.py
   ├── run.py
   ├── docs/
   │   ├── тз.rst
   │   ├── readme.rst
   │   ├── архитектура.rst
   │   └── отчёт.rst
   └── templates/
       └── index.html

Сборка документации
-------------------

Из папки ``docs``:

.. code-block:: bash

   python -m docutils --language=ru тз.rst тз.html

Открыть ``.html`` в браузере.
